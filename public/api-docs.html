Quick Start

1Install dependencies
npm install express axios express-validator express-rate-limit helmet cors dotenv morgan swagger-ui-express
npm install --save-dev nodemon jest
mkdir config controllers middleware public routes services utils
2Create source files
touch server.js .env .env.example .gitignore README.md
touch config/index.js config/swagger.js
touch controllers/askController.js controllers/impactController.js
touch controllers/alertsController.js controllers/sqlController.js
touch middleware/auth.js middleware/rateLimit.js middleware/validate.js middleware/errorHandler.js
touch public/api-docs.html
touch routes/index.js routes/ask.js routes/impact.js routes/alerts.js routes/sql.js routes/docs.js
touch services/openmetadata.js services/lineage.js services/formatter.js
touch utils/helpers.js
3Configure & run
cp .env.example .env
# Edit .env - set OPENMETADATA_BASE_URL and OPENMETADATA_BOT_TOKEN

npm run dev     # development with nodemon
npm start       # production

Token Security

Never commit the token to git

Store only in .env file

Non-expiring until manually revoked

Regenerate from OM UI if compromised

Never expose in responses or logs

Usage
# Add to every request header
Authorization: Bearer <your-token>

API Reference

Search the data catalog using natural language. Returns matching entities with metadata, FQN, and direct URLs.

AI Querycatalog searchentities
{
  "query": "customer"
}
{
  "success": true,
  "timestamp": "2026-04-21T03:25:59.520Z",
  "data": {
    "query": "customer",
    "answer": "Found 10 table(s) related to customer...",
    "sources": [
      {
        "name": "dim_customer",
        "fqn":  "sample_redshift.staging_db.integration.dim_customer",
        "type": "table",
        "url":  "https://sandbox.open-metadata.org/table/..."
      }
    ],
    "confidence": "medium"
  },
  "meta": { "requestId": "1776741959520-tw9wn5cjj" }
}
curl -X POST http://localhost:3000/api/v1/ask \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"query":"customer"}'

Analyzes downstream lineage to determine risk and affected assets for proposed schema changes.

Impact Analysislineagerisk scoring
{
  "table":  "sample_redshift.staging_db.integration.dim_customer",
  "change": "rename column customer_id to user_id"
}
{
  "success": true,
  "data": {
    "change": { "type": "rename", "severity": "high" },
    "riskScore": 0,
    "riskLevel": "low",
    "affectedAssets": {
      "upstream": [], "downstream": [],
      "totalUpstream": 0, "totalDownstream": 0
    },
    "recommendations": ["Use alias/view to maintain backward compatibility"]
  }
}
curl -X POST http://localhost:3000/api/v1/impact \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"table":"sample_redshift.staging_db.integration.dim_customer","change":"rename column customer_id to user_id"}'

Generates SQL queries using catalog schema context. Searches relevant tables and builds SQL from column metadata.

SQL GenerationNL to SQLschema context
{
  "question": "Show me total revenue by customer region",
  "tables":   ["sample_redshift.staging_db.integration.dim_customer"]
}
{
  "success": true,
  "data": {
    "sql": "SELECT customer_region, SUM(revenue) FROM dim_customer GROUP BY customer_region LIMIT 100;",
    "explanation": "Generated SQL using 1 table(s)",
    "tablesUsed": [
      { "name": "dim_customer", "columns": ["customer_key","customer_id","customer_region"] }
    ],
    "warnings": [],
    "estimatedComplexity": "simple"
  }
}
curl -X POST http://localhost:3000/api/v1/sql \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"question":"Show me total revenue by customer region","tables":["sample_redshift.staging_db.integration.dim_customer"]}'

Fetches test case results and formats alert payloads for external notification channels.

slackemailwebhookpagerdutyteams

  "data": {

Validation Rules

FieldRule
queryRequired · max 500 chars
table (FQN)Required · format: service.schema.table or deeper
changeRequired · max 200 chars
questionRequired · max 500 chars
tables[]Optional · max 10 items
testCaseIdRequired · valid UUID format
channels[]Required · min 1 · max 5 · slack | email | webhook | pagerduty | teams
